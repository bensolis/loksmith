# Loksmith

Turns one memorable passphrase into a strong, repeatable password for any site — derived entirely in your browser, the same way every time. Optionally sign in with a local account to save per-site settings (length, character types, exclusions) in this browser only.

## Usage

Open `index.html` in a browser, or visit the live site (see GitHub Pages link below once deployed).
