About & FAQ

How it works

You type a passphrase and a site name. Your browser runs both through a one-way cryptographic function to forge a password, using the exact same process every time. Because the process is deterministic, the same passphrase and site name always produce the same password. Nothing needs to be remembered, stored, or synced except the passphrase itself.

Why use this

There's no database of passwords to store, sync, or ever leak. Since nothing is saved anywhere, there's nothing for an attacker to steal in bulk. It works on any device with a browser, with no account, subscription, or extension required.

The trade-off: there's no "forgot password" recovery. If you forget your passphrase, or the exact site name and settings you used, that password cannot be regenerated. This also isn't a full password manager, so it won't autofill forms for you.

The technology

Your passphrase is stretched using PBKDF2-HMAC-SHA256A password-stretching function. It scrambles your passphrase over and over (100,000 times here) to make it far slower for an attacker to guess by brute force. with 100,000 iterations, then expanded with HKDFA technique for stretching one strong secret into as much extra output as needed, without weakening it. into a password of any length, with rejection samplingA method for picking characters fairly at random, so no character is ever more likely to appear than another. used to avoid bias in character selection. All of this runs through your browser's native Web Crypto APIThe set of secure cryptography tools built into every modern browser, used here instead of loading any outside code.. No server is involved at any point.

What's stored, where, and why

  • Passphrase: never stored anywhere. It exists only in the input field while you're using it, and is cleared the moment you sign in, sign out, or reload the page.
  • Generated password: never stored. It's computed fresh each time and shown on screen only.
  • Local account (optional): if you create one, your username is stored in plain text in this browser's local storage; your password is stored as a salted cryptographic hash, never in plain text. This feature is for convenience and for shared computers. It exists to help you remember the settings you used, since changing any setting changes your output. It is not for account security. See below.
  • Saved site profiles (optional): the site name and your chosen settings (length, character types, exclusions) are stored in this browser's local storage only. Never transmitted anywhere, and never synced between devices.
  • One external request: this page loads its fonts from Google Fonts each time it's opened, which is the one thing that leaves your browser. No app data is included in that request.

Security awareness

  • Keyloggers and compromised devices: your passphrase is typed into a normal text field. Any keylogger, malicious browser extension, or compromised device that can record your keystrokes can capture it, exactly as with any password typed anywhere. No web app can protect against a device that's already compromised.
  • A weak passphrase weakens everything: every password this tool generates traces back to one secret passphrase of your choice. A guessable passphrase undermines all of your forged passwords at once. The 100,000 PBKDF2 iterations slow down brute-force attempts, but they can't turn a weak passphrase into a strong one. That part is on you.
  • Shoulder-surfing and clipboard exposure: the show/hide toggle exists for a reason, so be mindful about revealing your passphrase in public. Once a password is copied, it also sits in your device's clipboard, where other apps or clipboard-history tools may be able to read it. That's the same risk as copying any password from anywhere.
  • The local login is a deterrent, not a lock: the account check runs entirely in your browser. Anyone with real technical access to this device could bypass it or read the saved site list directly.

Frequently asked questions

What happens if I forget my passphrase?

There's no way to recover it or the passwords it generates. Nothing is stored that could help reconstruct it, since that's a deliberate trade-off for never having anything to steal.

Why does changing the site name change the password?

The site name acts as a unique saltAn extra, unique input mixed in before the cryptographic process runs, so the same passphrase produces a different result for every site., so the same passphrase produces a different password for every site. Capitalization doesn't matter, since it's normalized, but a different name gives you a different password.

Is it a risk that this tool is open source, or that a hacker could see exactly how my password was generated?

No. A well-designed cryptographic system stays secure even when an attacker knows exactly how it works, as long as they don't know your passphrase. Real encryption standards are built this way too: publicly documented, with all the security resting on a secret key rather than a secret method. This app being open source means anyone, you included, can read its actual code and verify nothing is secretly stored or transmitted, rather than taking that on faith. The one thing that would actually put you at risk is someone learning your passphrase itself, not the method used to forge a password from it.

Can I use this on a shared or public computer?

You can, but be aware that anyone with access to the device afterward could read your saved site list from local storage, and the local login won't stop someone with real technical understanding. Avoid saving profiles on a computer you don't trust.

Why can't my saved sites follow me to another device?

Saved profiles live only in this browser's local storage. Nothing is ever sent to a server, so there's nothing to sync. You'd need to recreate your saved sites on each device you use.

What's "Key version" for?

It lets you generate a new password for the same site without changing your passphrase or the site name. This is useful if a site ever asks you to rotate a password.

Does this work offline?

Yes, once the page has loaded. Password generation runs entirely in your browser and needs no network connection.
